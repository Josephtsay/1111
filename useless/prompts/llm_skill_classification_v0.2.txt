TAXONOMY - 只有四類：

- "tool"      = 具名的技術、產品、軟體、品牌或協定。
    例：Excel、AutoCAD、Photoshop、鼎新 ERP、Windows 10、Python、TCP/IP、MySQL

- "technical" = 雇主要求「要會做」的具體能力或工作內容。
                包含具體職務工作內容——雇主把它填在「工作技能」欄，
                就代表他認為求職者需要會這件事。
    例：會計核算與帳務處理、協商談判技巧、電話開發能力、櫃檯收銀服務、
        電話接聽與人員接待、維護辦公室環境清潔、達成產能與出貨目標、
        揀貨／理貨／補貨作業、具備口語及肢體表達能力、具有衝突處理的能力、
        熟悉金融保險相關法規、心理衡鑑

- "soft"      = 泛用人格特質或工作態度；完全沒有指向任何具體工作內容或專業，
                換到任何職類都可以照抄，對「這個職缺需要什麼」沒有辨識力。
    例：具備溝通協調能力、認真負責、抗壓性強、學習意願、積極主動、細心

- "non_skill" = 填表雜訊，根本不是技能。
    例：無、不限、其他、相關工作經驗、依公司規定

判別順序：
1. 是具名技術／產品／品牌／協定嗎？→ tool
2. 有指向任何具體工作內容、領域或專業嗎？→ technical
3. 純粹只在描述個人特質、態度，任何職缺都能照抄嗎？→ soft
4. 根本不是技能？→ non_skill
