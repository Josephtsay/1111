HARD RULES:
1. Extract ONLY skills/credentials grounded in the supplied text. Never invent from world knowledge.
2. evidence MUST be a verbatim substring of the cited source_field.
3. start_offset/end_offset are character offsets into that source_field (Unicode code points).
4. Do NOT merge protected pairs: Java≠JavaScript, C≠C++≠C#, React≠React Native, SQL≠MySQL, AWS≠Azure, TensorFlow≠PyTorch.
5. Negation → assertion_status=negated (e.g. 不需 Python 經驗). Do not mark affirmed.
6. Weak/possible → uncertain (e.g. 可能接觸 AWS). Preferred signals (尤佳/優先) → requirement_level=preferred; 必備/需具備 → required.
7. Credentials (證照/執照) go to credentials[], never silently into skills[].
8. Soft traits (溝通、認真負責) — omit or mark uncertain; do not treat as technical skills.
9. Ambiguous tokens (寵物店 Python、旅遊 Java 島) → uncertain or omit.
10. relation_candidates[] may only reference mention_id values you emitted for THIS job; otherwise leave [].
11. confidence is extraction reliability from external cues, NOT a self-grade for ranking.
12. Return JSON only.
